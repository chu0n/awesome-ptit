## Ý tưởng

Các số có dư `p` khi chia cho `m` tạo thành cấp số cộng: `p, p+m, ...` nếu `p > 0`, hoặc `m, 2m, ...` nếu `p = 0`.

Tệ nhất là chọn hết nhóm này trước; vẫn chưa có số dư khác `p`. Chỉ cần thêm một số nữa là chắc chắn, trừ khi cả `n` số đều dư `p` thì in `0`.

`same = (n - first) / m + 1` nếu `first <= n`, ngược lại `same = 0`. Đáp án là `same + 1`, trừ khi `same == n`.

<details>
<summary><strong>Hướng 1 — Lời giải chính</strong></summary>

```cpp
#include <iostream>
using namespace std;

int main()
{
    long long limit, divisor, targetRemainder;
    cin >> limit >> divisor >> targetRemainder;

    // Số dương đầu tiên có đúng số dư cần tìm.
    long long firstNumber = targetRemainder == 0 ? divisor : targetRemainder;

    long long sameRemainderCount = 0;
    if (firstNumber <= limit) {
        // Đếm firstNumber, firstNumber + divisor, ... không vượt limit.
        sameRemainderCount = (limit - firstNumber) / divisor + 1;
    }

    if (sameRemainderCount == limit) {
        cout << 0;  // Không có số nào mang số dư khác.
    } else {
        cout << sameRemainderCount + 1;
    }
    return 0;
}
```

## Giải thích

- `firstNumber` là số dương đầu tiên có dư `p`: là `p` nếu `p > 0`, là `m` nếu `p = 0`.
- Nếu `firstNumber > n`, không có số nào dư `p`; `same = 0`, đáp án `1`.
- `sameRemainderCount` đếm các số `firstNumber, firstNumber + m, ...` không vượt `n`.
- Nếu `sameRemainderCount == n`, mọi số đều dư `p`; in `0`. Ngược lại in `sameRemainderCount + 1`.

**Độ phức tạp:** `O(1)` thời gian, `O(1)` bộ nhớ.

## Chạy tay

| Input | `first` | `same` | Kết quả |
|---|---:|---:|---:|
| `10 5 3` | 3 | 2 | 3 |
| `10 5 0` | 5 | 2 | 3 |
| `5 1 0` | 1 | 5 | 0 |

<summary><strong>Hướng 2 — quét trực tiếp</strong></summary>

```cpp
#include <iostream>
using namespace std;

int main()
{
    long long n, m, p;
    cin >> n >> m >> p;

    long long sameRemainderCount = 0;
    for (long long value = 1; value <= n; value++) {
        if (value % m == p) {
            sameRemainderCount++;
        }
    }

    if (sameRemainderCount == n) {
        cout << 0;
    } else {
        cout << sameRemainderCount + 1;
    }
    return 0;
}
```

Cách này đếm từng số từ `1` đến `n`; với `n ≤ 2^18` vẫn chạy nhanh, nhưng dài hơn công thức `O(1)`.
