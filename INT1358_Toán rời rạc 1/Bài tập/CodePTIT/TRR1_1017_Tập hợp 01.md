# TRR1_1017 — Tập hợp 01

> **Loại:** Lý thuyết tập hợp · **Thuật toán:** Quét bit, phép OR · **Thời gian:** O(n) · **Bộ nhớ:** O(n)

## Đề bài
> **TRR1_1017 - Tập hợp 01**
> 🔗 https://code.ptit.edu.vn/submit/TRR1_1017

**Mô tả:** Xét tập hợp `S` gồm `n` số nguyên dương đầu tiên. Mỗi tập con `A` của `S` có thể được biểu diễn dưới dạng xâu nhị phân `X` độ dài `n`, trong đó, `X[i] = 1` nếu số `i` (1 ≤ i ≤ n) là phần tử của tập `A` và `X[i] = 0` trong trường hợp ngược lại. Cho trước hai tập con `A` và `B` của tập `S`.

**Yêu cầu:** Xác định các phần tử của tập hợp là hợp của hai tập `A` và `B`.

**Giới hạn:** 
- Dòng đầu chứa số nguyên dương `n` không vượt quá 1000.
- Trong hai dòng tiếp theo, mỗi dòng chứa một xâu nhị phân độ dài `n` biểu diễn tập con `A` và `B`.
- Thời gian chạy ≤ 1 giây, bộ nhớ 64 MB.

**Kết quả:** Ghi ra tệp Output chuẩn gồm 2 dòng:
- Dòng đầu ghi số `k` là số lượng phần tử của tập hợp là hợp của hai tập `A` và `B`;
- Trong trường hợp `k > 0`, dòng thứ 2 ghi `k` số là các phần tử của tập hợp là hợp của hai tập `A` và `B` theo thứ tự tăng.

## Ý tưởng

- Bit `1` nghĩa là phần tử thuộc tập.
- Hợp: `u[i] = a[i] OR b[i]`.
- `k = Σu[i]`; phần tử `i` là số `i + 1`.
- Duyệt `i` tăng nên `result` tự tăng và không trùng.

<details>
<summary><strong>Hướng 1 — Lời giải chính</strong></summary>

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main()
{
    int n;
    cin >> n;

    vector<int> a(n), b(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    for (int i = 0; i < n; i++) {
        cin >> b[i];
    }

    // Tính hợp A ∪ B: vị trí i thuộc hợp nếu a[i]=1 HOẶC b[i]=1
    vector<int> result;
    for (int i = 0; i < n; i++) {
        if (a[i] == 1 || b[i] == 1) {
            result.push_back(i + 1);  // i+1 vì phần tử đánh số từ 1
        }
    }

    // Xuất kết quả
    int resultCount = static_cast<int>(result.size());
    cout << resultCount << "\n";
    for (int i = 0; i < resultCount; i++) {
        cout << result[i] << " \n"[i == resultCount - 1];
    }

    return 0;
}
```

### Giải thích nhanh

| Biến / thành phần | Vai trò |
|---|---|
| `a`, `b` | Hai dãy bit của tập A và B |
| `result` | Các phần tử thuộc hợp, tăng dần |
| `i` | Chỉ số 0-based; phần tử tương ứng `i + 1` |
| `resultCount` | Số phần tử hợp, in ở dòng đầu |

1. Đọc `n`, đọc đủ `n` bit của A rồi `n` bit của B.
2. Duyệt `i = 0..n-1`; nếu `a[i] == 1` hoặc `b[i] == 1`, thêm `i + 1` vào `result`.
3. In `result.size()`; nếu khác 0, in các phần tử cách nhau một dấu cách.
4. Không in dòng thứ hai khi hợp rỗng.

**Chỗ dễ sai**
- Dùng `&&` sẽ ra giao, không phải hợp.
- Lưu `i` thay vì `i + 1` làm lệch một đơn vị.
- Thêm phần tử hai lần khi cả hai bit bằng 1.
- In dòng thứ hai khi `k == 0`.

**Độ phức tạp:** `O(n)` thời gian, `O(n)` bộ nhớ.

## Chạy tay

Với `n = 5`, A = `0 1 0 0 1`, B = `1 1 0 0 0`:

| `i` | A | B | Phần tử | `result` |
|---:|---:|---:|---:|---|
| 0 | 0 | 1 | 1 | `[1]` |
| 1 | 1 | 1 | 2 | `[1, 2]` |
| 2 | 0 | 0 | không | `[1, 2]` |
| 4 | 1 | 0 | 5 | `[1, 2, 5]` |

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main()
{
    int n;
    cin >> n;

    vector<bool> inUnion(n + 1, false);

    for (int i = 1; i <= n; i++) {
        int bit;
        cin >> bit;
        if (bit == 1) {
            inUnion[i] = true;
        }
    }

    for (int i = 1; i <= n; i++) {
        int bit;
        cin >> bit;
        if (bit == 1) {
            inUnion[i] = true;
        }
    }

    int count = 0;
    for (int i = 1; i <= n; i++) {
        if (inUnion[i]) {
            count++;
        }
    }

    cout << count << '\n';
    if (count > 0) {
        bool first = true;
        for (int i = 1; i <= n; i++) {
            if (inUnion[i]) {
                if (!first) {
                    cout << ' ';
                }
                cout << i;
                first = false;
            }
        }
        cout << '\n';
    }
    return 0;
}
```

Đọc A và bật `inUnion[i]`, đọc B cũng bật; một mảng trạng thái nên không sinh trùng. Không cần lưu cả hai dãy bit.
