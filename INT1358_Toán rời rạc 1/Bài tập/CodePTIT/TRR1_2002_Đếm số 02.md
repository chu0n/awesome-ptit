**Mô tả:** Cho trước bốn số nguyên dương `a, b, k` và `m`.

**Yêu cầu:** Tìm số lượng `t` các số nguyên dương trong phạm vi từ `a` đến `b` là bội của `k` hoặc `m`.

**Giới hạn:** Vào từ tệp Input chuẩn gồm một dòng chứa bốn số nguyên dương `a, b, k` và `m`, mỗi số không vượt quá `2^18` và `a ≤ b` — thời gian chạy ≤ 1 giây, bộ nhớ 64 MB.

**Kết quả:** Ghi ra tệp Output chuẩn giá trị `t` tìm được.

## Ý tưởng

- Gọi `A` là tập bội của `k`, `B` là tập bội của `m` trong `[a,b]`.
- `|A ∪ B| = |A| + |B| - |A ∩ B|`.
- Bội chung là bội của `lcm(k,m)`.
- Số bội của `x` trong `[a,b]` là `b/x - (a-1)/x`.
- Tính `lcm = k / gcd(k,m) * m` để tránh tràn trung gian.

<details>
<summary><strong>Hướng 1 — Lời giải chính</strong></summary>

```cpp
#include <iostream>
#include <numeric>
using namespace std;

// Đếm số bội của x trong đoạn [a, b]
long long countMultiples(long long a, long long b, long long x)
{
    return b / x - (a - 1) / x;
}

int main()
{
    long long a, b, k, m;
    cin >> a >> b >> k >> m;

    long long lcm_km = k / gcd(k, m) * m;  // lcm(k,m) để tránh tràn số

    // Bao hàm - loại trừ: |bội(k) ∪ bội(m)| = |bội(k)| + |bội(m)| - |bội(lcm(k,m))|
    long long t = countMultiples(a, b, k) + countMultiples(a, b, m)
                - countMultiples(a, b, lcm_km);

    cout << t;
    return 0;
}
```

### Giải thích nhanh

| Biến / thành phần | Vai trò |
|---|---|
| `countMultiples(a,b,x)` | Đếm bội của `x` trong `[a,b]` |
| `gcd(k,m)` | Ước chung lớn nhất, theo Euclid |
| `lcm_km` | `k / gcd * m`, dùng đếm phần giao |
| `t` | Tổng bội của `k` hoặc `m` trong đoạn |

1. Đọc `a`, `b`, `k`, `m`.
2. Tính `lcm_km = k / gcd(k, m) * m`.
3. Cộng số bội của `k` và `m`, trừ số bội của `lcm_km`.
4. In `t`.

**Chỗ dễ sai**
- Dùng `b/x - a/x` thay vì `(a-1)/x` làm mất `a` khi `a` là bội.
- Quên trừ phần giao khiến bội chung bị đếm hai lần.
- Trừ bằng `gcd` thay vì `lcm`.
- Dùng `int` cho `lcm`; `2^36` tràn 32 bit.

**Độ phức tạp:** `O(log min(k, m))` thời gian do `gcd`; `O(1)` bộ nhớ.

## Chạy tay

Với `a = 1`, `b = 10`, `k = 2`, `m = 3`:

| Tập | Công thức | Số lượng |
|---|---|---:|
| Bội của 2 | `10/2 - 0/2` | 5 |
| Bội của 3 | `10/3 - 0/3` | 3 |
| Bội của 6 | `10/6 - 0/6` | 1 |
| Hợp | `5 + 3 - 1` | 7 |

<summary><strong>Hướng 2 — Duyệt trực tiếp từng số trong đoạn</strong></summary>

```cpp
#include <iostream>
using namespace std;

int main()
{
    long long a, b, k, m;
    cin >> a >> b >> k >> m;

    long long count = 0;
    for (long long value = a; value <= b; value++) {
        if (value % k == 0 || value % m == 0) {
            count++;
        }
    }

    cout << count;
    return 0;
}
```

Kiểm tra `value % k == 0 || value % m == 0` cho từng số. Dễ hiểu và không cần `lcm`, nhưng tốn `O(b-a+1)`.
