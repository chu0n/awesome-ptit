## Đề bài

> **TRR1_5005 - Chọn số 03**
> 🔗 https://code.ptit.edu.vn/submit/TRR1_5005

**Mô tả:** Cho trước ba số nguyên dương `n`, `m` và `p`. Tìm số lượng `t` ít nhất các số nguyên dương `x` không vượt quá `n` cần chọn ra để **chắc chắn** có số có số dư **khác** `p` khi chia cho `m`.

**Giới hạn:** `n, m, p ≤ 2^18`, `p < m` — thời gian chạy ≤ 1 giây.

| | Input | Output |
|---|---|---|
| Test 1 | `10 5 3` | `3` |

> **Giải thích Test 1:** Có 2 số nguyên dương `x` không vượt quá `n = 10` có số dư `p = 3` khi chia cho `m = 5` gồm `3` và `8`. Do đó chỉ cần chọn `t = 3` thì chắc chắn có số không có dạng chia cho 5 dư 3.

## Overview

| Trường | Nội dung |
|---|---|
| **Tên bài** | Chọn số 03 |
| **Mã bài** | TRR1_5005 |
| **Loại bài** | Toán rời rạc — Nguyên lý Dirichlet |
| **Mục đích** | Tìm số lượng số tối thiểu cần chọn để chắc chắn có số có dư khác `p` khi chia cho `m` |
| **Kiến thức** | Nguyên lý Dirichlet, cấp số cộng, phép chia dư |
| **Thuật toán** | Đếm `same` = số `x ∈ [1,n]` có `x mod m = p` (công thức cấp số cộng); nếu `same = n` (không tồn tại số có dư khác `p`) thì in `0`; ngược lại `t = same + 1` |

---

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    long long n, m, p;
    cin >> n >> m >> p;

    // Đếm số x trong [1, n] có x mod m == p
    long long same;
    if (p == 0) {
        same = n / m;                    // x = m, 2m, 3m, ...
    } else {
        same = (p <= n) ? (n - p) / m + 1 : 0;  // x = p, p+m, p+2m, ...
    }

    // Nếu mọi số trong [1,n] đều có dư = p → không tồn tại số có dư khác p
    if (same == n) { cout << 0; return 0; }

    // Tệ nhất chọn hết same số cùng dư p → thêm 1 chắc chắn có số dư khác p
    cout << same + 1;
    return 0;
}
```

---

**Giải thích logic:**

Các số `x ∈ [1, n]` thỏa `x mod m = p` tạo thành một **cấp số cộng**: `p, p+m, p+2m, ...` (nếu `p = 0` thì là `m, 2m, 3m, ...`).

$$\text{same} = \left\lfloor \frac{n-p}{m} \right\rfloor + 1 \quad (\text{với } p \geq 1,\ p \leq n)$$

Đây chính là số lượng phần tử tối đa mà đối thủ có thể chọn mà vẫn **chưa** có số dư khác `p` (mọi số đều dư đúng `p`). Chỉ cần chọn thêm **1** số nữa (chắc chắn phải có dư khác `p`, vì đã hết số dư `p`) → `t = same + 1`.

**Trường hợp đặc biệt:** Nếu `same = n` (tất cả các số từ `1` đến `n` đều có dư đúng `p` khi chia cho `m`), thì **không tồn tại** số nào có dư khác `p` → không thể chắc chắn, in `0`.

Kiểm tra Test 1 (`n=10, m=5, p=3`):
- `same = (10-3)/5 + 1 = 1 + 1 = 2` (các số 3, 8) ✓
- `same ≠ n` (2 ≠ 10) → `t = 2 + 1 = 3` ✓
