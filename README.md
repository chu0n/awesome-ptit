# PTIT Course Materials

Tài liệu học tập, bài tập và bài giải môn học tại PTIT.

## Cấu trúc

Mỗi môn một thư mục, tên theo dạng `<Mã môn>_<Tên môn>`. Cấu trúc chung bên trong:

```text
<Mã môn>_<Tên môn>/
├── Tài liệu/     bài giảng, slide, đề thi
├── Bài tập/      bài tập và lời giải
└── Ghi chú/      ghi chú cá nhân
```

Các môn hiện có:

- [`ELE1309_Điện tử số`](ELE1309_%C4%90i%E1%BB%87n%20t%E1%BB%AD%20s%E1%BB%91)
- [`SKD1101_Kỹ năng thuyết trình`](SKD1101_K%E1%BB%B9%20n%C4%83ng%20thuy%E1%BA%BFt%20tr%C3%ACnh)
- [`BSA12117_Pháp luật và sở hữu trí tuệ`](BSA12117_Ph%C3%A1p%20lu%E1%BA%ADt%20v%C3%A0%20s%E1%BB%9F%20h%E1%BB%AFu%20tr%C3%AD%20tu%E1%BB%87)
- [`INT1358_Toán rời rạc 1`](INT1358_To%C3%A1n%20r%E1%BB%9Di%20r%E1%BA%A1c%201)
